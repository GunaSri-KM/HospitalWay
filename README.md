# 🏥 HospitalWay – Smart Indoor Hospital Navigation

HospitalWay is a smart indoor hospital navigation and assistance system designed to help patients and visitors easily find hospital departments, facilities, and destinations.

The system provides destination search, interactive route guidance, floor-aware navigation, and visual hospital map assistance to make hospital navigation simpler and more accessible.

## 🔄 How It Works

1. Search for a hospital department or facility.
2. Select the required destination.
3. HospitalWay identifies the destination floor and room.
4. The system generates an appropriate route.
5. Users receive visual guidance through the hospital map.
6. Floor changes and lift requirements are displayed automatically.
7. The user follows the route until reaching the destination.

## 🎯 Problem Solved

Large hospitals can be difficult to navigate, especially for first-time visitors, elderly patients, and people unfamiliar with the building layout.

HospitalWay addresses this problem by providing a simple digital navigation experience that helps users locate hospital departments and facilities quickly.
